# longBlog macOS 0.2.0 — 写作体验与稳定性

## 编辑器

- 全新原生 Markdown 编辑器（NSTextView）：语法高亮（标题、强调、代码、链接、公式、引用、列表、表格）、中文输入法安全、完整撤销。
- **分栏实时预览**：阅读 / 编辑 / 分栏三种视图（⌘⌥R / ⌘⌥E / ⌘⌥P），预览随输入防抖刷新（KaTeX、Mermaid、本地图片），可跟随编辑器滚动。
- 格式工具栏与“格式”菜单：粗体 ⌘B、斜体 ⌘I、删除线 ⌘⇧X、行内代码 ⌘⇧C、链接 ⌘K、图片 ⌘⇧I、标题 ⌘⌥1–3、引用 ⌘'、无序 / 有序 / 任务列表 ⌘⇧8 / ⌘⇧7 / ⌘⇧9、代码块 ⌘⇧K、表格 ⌘⌥T、分隔线 ⌘⌥-、公式 ⌘⌥M / ⌘⌥⇧M。
- 列表回车自动续写（空项回车结束列表）、Tab / ⇧Tab 缩进、选中文字后输入括号或 * 等自动包裹、粘贴 URL 到选中文字生成链接。
- 直接**粘贴截图或拖入文件**即可导入附件，并在光标处插入 Markdown；未保存的文章会先自动保存再导入。
- 大纲跳转、编辑器内查找（⌘F）、字数 / 阅读时长统计、字号与等宽字体设置。

## 界面

- 侧边栏延伸至标题栏并使用原生半透明材质；工作区快捷键 ⌘1–⌘5；标题栏显示副标题（文章数、目录、未读等）。
- 新增浅色外观，可在“显示 → 外观”或连接设置中选择跟随系统 / 浅色 / 深色（默认深色）。
- 列表卡片悬停反馈、待提交 / 未保存 / 图片 / 标签标记、右键“在 Finder 中显示”；成功提示自动淡出，提示浮层不再挤压布局。

## 问题修复

- **指定文章文件夹卡住**：原先在“连接设置”表单内用 SwiftUI 文件选择器，随后的确认框被挂到被表单遮住的主窗口上而不可见，整个界面处于锁定状态。现改为挂在当前表单上的原生 NSOpenPanel，所有确认框统一挂到最上层窗口；目录切换在文章队列后串行执行，并清空旧目录的编辑缓冲。新增“恢复默认”和“在 Finder 中显示”。
- **钥匙串弹窗反复冻结界面**：ad-hoc 签名每次更新都会触发钥匙串授权，而读取发生在主线程且被反复调用。现每个钥匙串项目每次启动最多读取一次并缓存。
- 主窗口改由 AppDelegate 唯一管理：不再因窗口恢复出现两个工作区窗口、菜单命令被执行两次的问题。
- 文章列表加载中按 ⌘N / 选择文章不再被静默忽略，改为加载完成后执行。
- 兼容 Xcode 27 的 `lipo -verify_arch`。

# longBlog macOS 0.1.0 — 预览版

首个独立 macOS 移植版本，以 longBlog-iOS `6245c808b4d612d656e86b87f69125fa7331d1c2` 为业务基线。

- SwiftUI / AppKit 原生窗口、五入口侧边栏与暖棕玻璃风，依据随仓库保存的设计草稿。
- Objective-C 复用文章目录、暂存/批量提交、冲突/未决事务保护、dotenv、GitHub、legacy Memos、终端留言协议。
- 离线 WebKit Markdown、数学与图表渲染，受控本地资源与外链处理。
- AI 流式生成、取消、预览与手动应用。
- Apple Silicon / Intel 通用 DMG；干净编译、原生边界 fixture、包完整性检查与窗口启动冒烟测试由 GitHub Actions 执行。

## 重要说明

这是需要实际 Mac 验收的**预览版本**，不是宣称已完成所有 iOS 功能和全部交互验收的正式版。具体移植差异见仓库 `docs/UI-PORT.md`、`docs/CORE-PORT.md`、`docs/READER-PORT.md`。

程序仅作 ad-hoc 签名，**没有 Developer ID 签名及 Apple 公证**；首次打开可能需要系统设置授权。不要全局关闭 Gatekeeper。安装方法见 `docs/INSTALL.md`。

客户端不包含站点后端、Memos 服务、持续消息推送或部署服务。Token 和 API Key 需要使用者自行配置；请先连接测试仓库，备份已有文章。CI 未使用真实私人服务执行回复、发布、删除或站点配置提交。设计目录中的截图是参考稿，不是实际运行截图；实际 CI 窗口截图在 Actions 的 smoke artifact 中。
